- Exploratory Data Analysis
- Business Intelligence
- Customer Segmentation
- Churn Analysis
- Machine Learning Prediction
- Feature Importance Analysis

- Pandas
- NumPy
- Matplotlib

## Machine Learning

Model Used:
- Random Forest Classifier

Successfully predicted customer churn and identified key factors influencing customer retention.
